# Naitik Pathak — Portfolio

Premium, responsive React portfolio built with Vite. Project details are centralized in `src/data.js`; profile and social links are in the `profile` object there.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The static site uses no paid APIs or backend. Profile details and links are centralized in `src/data.js`. GitHub links are included for CropCare and SLM Arena from the supplied resume; add repository/demo links for other projects if you want them shown. Project filters, pointer-reactive cards, the skills selector, and the connected-field lab are interactive. OptiVest's case study includes a keyboard-accessible sample allocation control, labeled synthetic and separate from the project's research results. `public/Naitik-Pathak-Resume.pdf` is the resume download.

## Content notes

- OptiVest AI and QuantOpt are separate projects.
- QuantOpt's case study calls out its negative holdout results.
- The saved CropCare evaluation reports disagree, so no definitive accuracy is advertised.
- SteelLens results distinguish the four-company, ten-company, and Tata Steel ESG workflows.
- SLM Arena is listed as a resume-only project because its folder was not part of the reviewed project set.
- Project graphics are original interface illustrations. Where numbers are not real project outputs, the graphic labels say schematic, concept, or simulated view.
